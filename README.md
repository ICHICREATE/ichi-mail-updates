# ICHI MAIL updates

This public repository is reserved for signed Windows update packages and their update index.

There is no customer update available yet. The current [index](index.json) lists zero releases, and no application is available to download until Windows build and acceptance checks are complete.

The application source, signing keys, customer data, settings, Gmail credentials, test PDFs, and owner-only build materials are not stored here. A customer update is installed only after its signature and package contents pass the app's local checks. Preparing or downloading an update never authorizes email sending.

For support, contact the person who supplied your ICHI MAIL installation. Do not use GitHub's automatically generated source archives as an installer.
